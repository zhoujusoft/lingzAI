# lingzAI V1.8.0 版本更新记录：对话更好认，渠道更好接，权限更清楚

`V1.8.0` 这一版主要解决一个问题：

> lingzAI 的入口越来越多、能力越来越多以后，用户能不能一眼看明白自己正在用什么、消息从哪里来、这个 Agent 能做什么？

所以这次升级不只是加功能，也重点优化了界面体验。简单说，就是：

- 会话列表更清楚了
- 对话类型更好区分了
- 企业微信、钉钉、微信等渠道接入更顺了
- Agent 设置页更好用了
- 技能和工具权限边界更清楚了
- 部署和运行目录也继续做了整理

---

## 一、本次重点更新

### 1. 会话列表更好认

以前左侧会话记录主要显示“第一条问题”和“最近消息”，会话一多就不太好找。

现在会话记录改成了两层信息：

- 上面显示会话类型，比如：对话 极速模式、对话 任务模式、技能、企业微信、钉钉、微信
- 下面显示技能名称、渠道名称和会话总结标题

这样用户不用点进去，也能大概知道：

- 这是不是普通对话？
- 是极速模式还是任务模式？
- 是哪个技能产生的会话？
- 是不是来自企业微信、钉钉或微信？
- 这段会话大概在聊什么？

这对会话历史比较多的场景很有用，左侧列表不再只是消息堆在一起，而是更像一个“工作记录目录”。

### 2. 对话模式区分更清楚

这一版把对话入口进一步拆清楚了。

目前会区分：

- 对话 极速模式
- 对话 任务模式
- 技能对话
- 渠道对话

极速模式更适合日常问答、快速沟通、简单确认。  
任务模式更适合多步骤处理、工具调用、文件处理、生成结果这类复杂任务。

界面上也会直接显示“对话 极速模式”，用户能更明确知道当前是哪种对话。

同时，渠道对话和任务模式历史会话进入查看状态时，输入框和按钮会禁用，避免用户误以为还能继续在原会话里发起操作。

### 3. 图标和渠道 Logo 更直观

这次统一整理了会话列表和 Agent 设置里的图标展示。

现在规则更简单：

- 普通对话使用 Agent 图标
- 技能对话使用技能自己的图标
- 渠道对话显示对应渠道 Logo
- 企业微信、钉钉、微信分别显示自己的标识

这样列表里同时出现普通对话、技能对话、企业微信消息、钉钉消息时，不需要靠读一长串文字判断来源，看图标就能先分辨出来。

也修复了企业微信名称显示不全、打开预览区后 Agent 图标错位等细节问题。

### 4. 渠道接入继续完善

`V1.8.0` 继续补强企业微信、钉钉、微信这类外部渠道接入。

主要包括：

- Agent 设置里可以看到渠道入口
- 渠道添加弹层点击空白区域会自动收起
- 渠道列表和会话记录里显示对应渠道 Logo
- 企业微信显示更完整
- 钉钉 Stream 消息链路继续完善
- 渠道文件消息可以进入聊天附件
- 渠道生成的文件结果可以更好地发送出去
- 渠道消息去重、非文本提示、输入中状态等细节继续优化

还有一个比较关键的后台逻辑：  
外部渠道消息进来时，会按用户和账号绑定关系找到正确的 Agent、用户和会话，不再简单走一套公共入口。

换句话说，企业微信、钉钉、微信不只是“能接进来”，而是更接近真实企业使用里的多账号、多用户、多渠道场景。

### 5. Agent 设置更完整

这一版继续优化个人 Agent 设置页。

用户可以更清楚地看到和维护：

- 当前 Agent 信息
- Agent 头像
- 已启用技能
- 个人技能偏好
- 渠道绑定入口

技能启用也更符合实际权限：

- 如果用户没单独配置偏好，默认使用角色授权的技能
- 如果用户配置了偏好，只能在角色授权范围内选择
- 用户看不到、也用不了自己没有权限的技能

这样 Agent 设置不再只是一个配置页，更像用户自己的 Agent 工作入口。

### 6. 技能和工具权限边界更清楚

这一版继续收口资源权限逻辑。

简单说就是：

- 用户有什么技能权限，提示词里才会展示什么技能
- 用户有什么工具权限，运行时才会注入什么工具
- 没有权限的技能和工具，不会提前暴露给模型

这样做比“等工具真正执行时再拦截”更清楚。  
模型从一开始就只看到当前用户能用的能力，减少误调用，也更适合企业权限管理。

### 7. 部署和运行目录更规整

部署和本地运行目录也做了整理。

本地后端运行时，默认工作区收敛到仓库根目录的 `workspaces`。  
Docker 部署时，容器内继续使用 `/app/workspaces`。

这样技能运行、用户会话文件、渠道文件、生成结果等内容都有更明确的位置，不会混在源码目录里。

同时也把 vLLM tool calls 调试脚本整理到了 `deploy/lingz/scripts/vllm-tool-calls/`，方便部署现场排查模型工具调用问题。

## 二、界面优化汇总

这一版做了不少前台细节优化：

- 左侧“聊天”改成“对话”，更符合现在多模式入口
- 会话记录显示会话类型和总结标题
- 对话、技能、渠道使用不同图标或 Logo
- 企业微信名称显示更完整
- Agent 图标在预览区打开后不再错位
- 渠道添加弹层支持点击外部关闭
- 任务模式和渠道历史会话禁用输入框与按钮
- 按钮、列表、弹层、图标对齐继续优化

这些不是特别大的单点功能，但会明显影响日常使用体验。  
尤其是会话多、渠道多、Agent 多的时候，界面更清楚就很重要。

## 三、适合怎么理解 V1.8.0

如果用一句话概括：

> `V1.8.0` 是一次“把复杂能力变得更好用、更好认、更好管”的升级。

它让 lingzAI 不只是功能更多，而是更适合企业真实场景：

- 员工知道自己正在用哪种对话
- 管理员能更清楚地配置技能和渠道
- 外部渠道消息能更准确地进入对应会话
- 权限控制更贴近企业管理要求
- 界面不再让用户靠猜来判断来源和状态
