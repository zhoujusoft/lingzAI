# lingzAI V1.4.2 功能清单（基于 V1.3.3 之后增量整理）

> 当前版本号为 `V1.4.2`。本文基于当前仓库已落地功能整理，重点补齐 `V1.3.3` 发布之后持续新增的能力，仅记录已经进入代码与数据库脚本的内容，不包含仍停留在 PRD、讨论稿或规划阶段的事项。

如果说 `V1.3.3` 解决的是“企业 Agent 如何创建、发布、接入和运行”，那么当前版本继续补上的，是这条生产线真正走向日常运营所需要的治理能力：

- 用户怎么注册、校验和创建
- 模型怎么切换、统计和限额
- 后台菜单怎么按角色收敛
- 知识库、数据源、数据集、MCP 怎么做资源权限
- 技能工坊怎么在额度和工具边界内稳定运行
- 系统品牌、渠道运行态、业务模板技能怎么进一步落地

---

## 相比 V1.3.3 的核心增量

### 1. 用户体系与登录安全增强

- 新增登录验证码能力，登录页需先获取验证码再完成账号校验。
- 新增前台注册页，支持站内新用户发起注册申请。
- 新增隐藏式 `register-user` 技能，管理员可通过对话式流程完成“预览摘要 -> 确认创建”式用户创建。
- `register-user` 技能包含专属原生工具：
  - `register_user_preview`
  - `register_user_confirm`
- 管理员可在不暴露后台复杂表单的情况下，直接用 Agent 完成基础用户录入。

### 2. 对话模型切换与 Token 治理上线

- 通用聊天支持手动切换对话模型，模型选择绑定到当前会话而不是仅单次请求。
- 会话恢复时可带回当前会话绑定模型，模型失效时会明确提示用户重新选择。
- 会话、消息与 usage 统计链路补齐实际运行模型信息，包括：
  - `chat_model_id`
  - `model_id`
  - `model_name`
  - `adapter_type`
  - `llm_call_count`
- 新增站内用户 `Token` 额度体系：
  - 系统级开关
  - 新用户初始额度配置
  - 管理员发放额度
  - 管理员修改剩余额度/不限量状态
  - 前台展示剩余额度与已用量
- 聊天、知识库问答、技能工坊创建对话、技能工坊试运行已经统一接入额度校验与扣减链路。

### 3. 后台权限治理从“统一后台”走向“按角色可见”

- 新增角色菜单权限表 `sys_role_menu_permission`。
- 后台路由、侧边栏、页面入口支持按 `permissionKey` 做可见性控制。
- 角色管理已支持维护菜单权限分组，覆盖：
  - 内容与技能
  - 接入与模型
  - 资源目录
  - 系统管理
- 普通用户不再默认看到全部后台入口，后台开始具备基础的“角色可见范围”控制能力。

### 4. 资源级权限从知识库扩展到更多核心资源

- 知识库新增 `ownerUserId + permissionScope` 权限模型，支持三档资源范围：
  - 仅创建人可见可操作
  - 所有人可见，仅创建人可操作
  - 所有人可见可操作
- 知识库权限会同步到发布后的工具可见性与技能绑定可绑定性。
- 当前同类资源权限模型已扩展到：
  - 数据源
  - 数据集
  - MCP 服务
  - 工具目录项
- 这意味着平台不再只是“有资源就全员共用”，而是开始具备面向企业内部协作的资源隔离与共享策略。

### 5. 技能工坊继续补齐治理能力

- 工具库新增“全局可用”开关 `enabled_global`，可区分：
  - 全局注入对话
  - 仅按需绑定/使用
- 技能工坊新增工具自动绑定能力，降低项目初始化时的人工配置成本。
- 技能工坊项目设置页支持按工具类型筛选可绑定工具。
- 技能工坊创建对话与试运行已统一接入用户 `Token` 限额规则。
- 技能运行时开始支持“按 runtime skill name 注入专属原生工具”，为 `register-user` 这类技能专属工具提供隔离机制。

### 6. 系统品牌与前后台体验可配置

- 新增系统品牌配置，支持维护：
  - 系统名称
  - Logo
  - Favicon
- 登录页、注册页、前台导航、后台导航、浏览器页签图标会同步读取品牌配置。
- 平台开始支持从“默认产品皮肤”切换到“客户自有品牌外观”。

### 7. 渠道接入进入“按用户运行态管理”阶段

- 企业微信渠道进一步增强认证与多账号支持。
- 微信/企业微信渠道运行态按 `ownerUserId` 隔离。
- 渠道登录态支持保存、恢复、失效清理与重连。
- 渠道适配器已支持 typing 状态、消息去重、用户级会话绑定等更完整的运行细节。
- 渠道能力从 `V1.3.3` 的“基础接入”继续走向“可长期运行与维护”。

### 8. 业务模板技能持续扩充

- 新增或补齐多类业务技能样板，包括：
  - 会议助手
  - 项目管理助手
  - 销售信息助手
  - 销售客户工作台
  - 销售协同/销售助手
  - 铜价分析类技能
- 平台能力不再只停留在通用 Agent 底座，而是持续沉淀可直接复用的行业/业务模板。

## 当前版本能力总览

### 1. 对话与 Agent 入口

- 支持通用聊天、技能聊天、知识库问答、数据集问答、独立 Chatbot、渠道接入等多入口对话。
- 支持会话列表、历史消息、会话重命名、会话删除、会话模型恢复等基础会话治理。
- 支持会话级模型切换与运行模型追踪，前台对话不再强依赖单一默认模型。
- 支持附件、运行时工具、结构化渲染与多轮工具调用记录，持续向执行型 Agent 演进。

### 2. 技能体系与技能工坊

- 支持技能目录管理、展示信息维护、工具绑定、运行时刷新、技能包导入导出。
- 支持技能工坊项目创建、文件树查看、项目对话式编辑、项目设置维护、工具自动绑定、试运行。
- 支持技能发布为独立 Chatbot，并通过 `appCode` 对外访问。
- 支持技能专属原生工具注入，满足“技能能力可复用、内部工具不外泄”的隔离诉求。

### 3. 知识库与 Agentic RAG

- 支持知识库创建、文档上传、解析、分块、重试、文档树管理、召回测试与流式问答。
- 支持知识库发布为工具，接入技能编排链路。
- 支持知识库资源权限、工具权限同步、技能绑定权限收敛。
- 已具备“知识检索 + 工具调用 + 前端结构化展示”的 Agentic RAG 基础能力。

### 4. 数据源、数据集与智能问数

- 支持数据源连接测试、对象探查、字段探查、关系探查。
- 支持数据集创建、编辑、详情查看、发布为工具、问数对话。
- 数据源与数据集已经纳入 `owner + permissionScope` 资源权限治理。
- 为“业务库表理解 -> 问数执行 -> 工具化复用”提供了更稳定的资源管理基础。

### 5. MCP、API 与工具库治理

- 支持 MCP Server 新增、编辑、刷新、删除、详情查看。
- MCP 已支持资源权限字段与可见性控制。
- 支持低代码 API 注册为系统工具、测试执行、取消注册。
- 工具库支持：
  - 绑定能力标记
  - 全局可用开关
  - 发布态工具目录
  - 技能绑定过滤
  - 资源权限透传

### 6. 渠道接入与外部运行

- 支持 Webhook、微信 iLink、企业微信等渠道能力。
- 支持渠道启动、停止、重启、登录态管理、用户绑定、会话桥接。
- 支持渠道消息路由到通用聊天、技能聊天、知识问答等内部会话链路。

### 7. 用户、角色与系统配置

- 支持用户管理、登录态刷新、退出登录、单点换取 token、用户额度管理。
- 支持角色管理与菜单权限配置。
- 支持系统品牌配置、平台配置、Token 额度配置。
- 平台开始具备“账号体系 + 权限体系 + 品牌体系 + 额度体系”四条运营治理链路。

### 8. 部署与开源支持

- 提供本地开发、后端启动、前端启动、Docker Compose 快速体验等部署方式。
- 提供数据库变更脚本、迁移脚本、发布脚本与版本更新文档。
- 适合继续用于本地开发、私有化部署和后续版本发布沉淀。

## 一句话总结

`V1.3.3` 之后，lingzAI 不只是继续加功能，而是在把企业 Agent 平台真正补成一个“可上线、可控权、可限额、可运营、可复用”的长期系统。
